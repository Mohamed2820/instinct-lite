# التوقيع (مفتاح الإصدار الثابت)

**الحالة: متوقّف. مفيش مفتاح اتولّد، ومفيش خطوة هنا مطلوبة منك دلوقتي.**

الشرط اللي طلبته: المفتاح يتولّد في workflow منفصل، يتخزّن كـ Secret مشفّر، ويتنزّل عندك مرة واحدة **كـ artifact خاص**.

حقايق من وثائق GitHub بتمنع ده بالشكل ده على ريبو عام:

- الـ workflow بالـ token الافتراضي مش بيقدر يكتب Secrets (جدول صلاحيات GITHUB_TOKEN مفيهوش صلاحية للـ secrets). الكتابة بالـ API محتاجة token بصلاحية أعلى (PAT أو GitHub App)، وده ممنوع نعمله من غير قرارك.
- الـ artifacts على ريبو عام بينزّلها أي حد عنده حساب GitHub (التنزيل بيحتاج صلاحية قراءة بس). يعني مفيش artifact «خاص» على ريبو عام.

علشان كده ملف التوليد اتنقل لـ `docs/pending/generate-keystore.yml.DISABLED` وهو **مش workflow شغال**. مفيش أي workflow بيرفع مفتاح. أي تصميم بديل (ريبو خاص، أو توليد المفتاح بمعرفتك من طريقة تختارها إنت) قرار ليك، وماحدّش هيفترض موافقتك عليه.

## البناء
- `debug`: بيشتغل من غير أي Secret.
- `release`: بيتوقّع Secrets (`SIGNING_KEYSTORE_BASE64` و`SIGNING_KEYSTORE_PASSWORD` و`SIGNING_KEY_ALIAS`) ويفشل برسالة واضحة لو ناقصة. مابيوقّعش أبدًا بمفتاح debug. من غيرهم مفيش APK release موقّع.
- ماتمسحش تطبيقك المثبّت، وبياناتك ماتتمسّحش بسبب أي خطوة هنا.
